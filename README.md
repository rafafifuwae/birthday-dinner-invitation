# Birthday Dinner Invitation

Live: https://rafafifuwae.github.io/birthday-dinner-invitation/

A standalone art-deco invitation card — Friday, 4 September 2026, 20.00 WIB,
Donna Bar & Lounge.

## Files

- `index.html` — the page that is served. Self-contained; no build step needed to view.
- `og.png` — the thumbnail WhatsApp and other apps show for the link.
- `source.html` — the same page without the `<head>`, kept for re-generating `index.html`.
- `build-site.js` — wraps `source.html` back into `index.html` (`node build-site.js`).

## Editing

For a quick text change, edit `index.html` directly, commit, and push —
GitHub Pages redeploys in about a minute.
